# Media

Folders, put your own photos and videos here:

- `printing/` printing, parts on the bed, parts laid out
- `assembly/` legs, body, servos being fitted
- `electronics/` wiring, Mega, power, remote internals
- `arm/` arm build and mounting
- `final/` finished robot, walking, gripping. Include at least one video if you can.

Compress large files before committing. Use short, descriptive file names
(`leg_assembly_03.jpg`, `walking_test.mp4`).
